# Templates

ApiForge generates projects programmatically via `@apiforge/codegen` (`packages/codegen/src/stacks/`).

Stack ids:

| Id | Output |
|----|--------|
| `net-minimal` | .NET 8 Minimal API |
| `net-webapi` | .NET 8 Web API Controllers |
| `node-express` | Node.js Express + TypeScript |
| `node-fastify` | Node.js Fastify + TypeScript |

See `packages/codegen` to extend or customize generators.
